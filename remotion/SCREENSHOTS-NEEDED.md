## Screenshot Specifications

- **Resolution**: 1920x1080 (Full HD)
- **Format**: PNG (lossless)
- **Aspect Ratio**: 16:9
- **File Size**: Compress if over 500KB

## Capturing Tips

1. **Visualizers**: Use Control Room, enable visualizer, let it run for 10-15s, capture best frame
2. **Control Room UI**: Use browser dev tools to zoom/crop specific sections
3. **Code Editor**: Use VS Code with Monokai/Dark+ theme
4. **Stock Photos**: Use Unsplash, Pexels, or similar (CC0 license)
5. **Mockups**: Use Screely.com or similar for device mockups

## Testing After Capture

Run `npm run dev` in remotion directory and check each video composition to verify:
- Screenshots load correctly
- No fallback placeholders visible
- Timing feels right with actual content
- Text overlays remain readable
